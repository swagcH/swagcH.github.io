无敌杰尼龟

Java 后端工程师 · 杰尼龟的笔记作者

从 2018 年开始系统学习 Java，并持续记录从语言基础、业务交付到架构演进和生产问题治理的真实过程。这个博客既是技术备忘录，也是一份可以公开检验的成长轨迹。

我关注代码是否容易继续修改、系统失败时能否快速恢复，以及团队能否把一次经验变成长期能力。2025 年开始，我也在实践如何让 AI 进入需求分析、代码修改、测试和审查流程，而不是只生成一段看起来正确的代码。

2022.03 - 2024.04

深圳小信科技有限公司 · Java 开发工程师（研发部）

担任两个医疗行业系统的后端主程，负责核心模块设计与开发。

  • 医院电子通行证系统（后端主程）—— 5 个微服务模块、1067 个 Java 文件、约 389 个 REST 接口、265 个数据实体，十余家医院在用。
    技术栈：SpringCloud · RabbitMQ · ShardingSphere · ElasticSearch · Redis · MQTT · HL7。
    负责出入记录与门禁管理等核心模块；主导多厂商门禁设备的 MQTT 统一接入、与医院既有信息系统的 HL7 数据交换、通行记录的分库分表改造。
  • 病案无纸化管理系统（后端主程）—— 覆盖采集、归档、打印、借阅、封存解封、质控、召回完整流程，整合十余类临床文档。
    技术栈：SpringBoot · MySQL · Redis · MinIO。
    负责借阅与封存解封模块；用 MinIO 承载病案文档对象存储，基于 Redis 记录并限制用户下载次数。

成长路径

2018 - 2019

建立 Java 与 Web 开发基础

从语言、集合、异常与 JDBC 起步，逐步进入 Servlet、Spring、MyBatis，并完成第一个端到端的完整项目。这个阶段解决的问题是"能写出来"。

2020 - 2022

从功能开发走向独立交付

在企业项目中独立承担模块的设计与落地，开始系统整理代码规范、数据库设计、接口文档与部署流程。关注点从"功能能跑"转向"别人能不能接手"。

2022 - 2024

深入复杂业务与生产稳定性

作为后端主程负责医疗行业系统：多厂商门禁设备的统一接入（MQTT）、与医院既有信息系统的 HL7 数据交换、通行记录的高频写入瓶颈（分库分表）。把线上问题的排查过程沉淀为可复用的证据链方法。

2024 - 2026

从模块负责人到技术负责人

主导集团级数据大屏的后端架构：微服务边界划分、9 个异构系统的数据集成与 580 个指标口径统一、4 台服务器约束下的高可用取舍，并推动对象存储与并行聚合等改造落地。开始为技术决策的代价负责。

2025 - 至今

把 AI 纳入真实开发流程

与技术负责人阶段并行推进：围绕上下文工程、Vibe Coding、Java 重构与个人工作流，验证 AI 的效率收益与责任边界，并把结论沉淀为自建模型网关、运维自动化等可复用基础设施。
