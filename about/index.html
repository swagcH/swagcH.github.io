Java 后端开发者 · 杰尼龟的笔记作者

从 2018 年开始系统学习 Java，并持续记录从基础开发到工程实践、架构演进的真实过程。这个博客既是我的技术备忘录，也是一份公开的成长轨迹。

我关注代码的可维护性、系统的稳定性，以及问题背后可复用的方法。这里不追逐概念热度，更希望把踩过的坑、做过的取舍和验证过的方案讲清楚。
