2022.03 - 2024.04
基于电子签名技术实现无纸化归档的电子病案管理系统。整合各临床信息系统数据形成完整电子病案卷宗，使病案可脱离原系统独立展示与查阅。功能覆盖数据采集、归档、打印、借阅、封存、质控、召回的完整生命周期。
技术栈：SpringBoot · MySQL · Redis · MinIO · 电子签名
  • 多来源文档整合：一份完整病案由住院病案首页、入院记录、手术知情同意书、护理记录单、各类检查报告等十余种文档构成，来源系统各异。需要把分散在多个临床信息系统的数据汇聚成可独立展示的完整卷宗
  • 大文件存储与并发：病案文档体积大、数量多，本地文件系统并发上传下载表现不佳。改用 MinIO 对象存储，把文件读写从应用服务器剥离
  • 数据安全与合规：病案属敏感数据，借阅场景存在恶意重复下载风险。基于 Redis 记录并限制下载次数，同时保证正常业务不受影响
