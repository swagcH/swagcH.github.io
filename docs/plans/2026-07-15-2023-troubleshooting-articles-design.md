# 2023 年 SQL 与服务器排障文章设计

## 目标

补齐博客 2023 年内容，延续现有文章偏个人记录、问题驱动和命令可复现的写法。五篇文章不做百科式概念堆砌，而是围绕后端开发常见现场展开：先描述现象和影响，再给出排查路径、关键命令、判断依据、修复方式以及复盘清单。

## 内容结构

每篇统一采用“写在前面、现场现象、排查过程、根因分析、处理方案、复盘清单”的结构。SQL 文章使用可执行的 MySQL 示例，并区分 MySQL 5.7 与 8.0 的能力差异；服务器文章从系统指标逐层定位到进程和线程，Java 部分以 JDK 8 可用命令为基准。涉及 `jmap`、删除日志、清理缓存等高风险动作时，必须说明影响和替代方案。
