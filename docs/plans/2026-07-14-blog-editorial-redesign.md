# 博客编辑型视觉重构设计

## 目标

以用户提供的关于、分类、归档和文章详情四张设计图为唯一视觉基准，将现有深色霓虹主题替换为适合程序员博客的浅色编辑型界面。保留“杰尼龟的笔记”和“无敌杰尼龟”的真实品牌信息，不虚构文章、分类、阅读量或任职公司。

## 视觉系统

- 页面使用浅灰背景和居中白色站点画布。
- 标题使用中文衬线字体，正文使用系统无衬线字体，代码使用等宽字体。
- 主色为紫色，仅用于标题短线、筛选状态、分类标签、引用和交互反馈。
- 采用细灰分隔线、大留白和低圆角，不使用渐变、霓虹和装饰性卡片堆叠。
- 桌面端内容画布最大宽度为 1280px；文章正文控制在约 760px；移动端改为全宽并保留 20px 内容边距。

## 页面结构

- 关于页：页面标题、作者介绍、技术栈、实践经历和联系方式。
- 分类页：真实分类的双列网格、文章数量和方向说明，以及从真实文章数据中选取的分类精选。
- 归档页：真实文章的完整年份分组、分类筛选、日期、标题和分类列。
- 文章页：作者与元数据栏、居中标题与摘要、窄正文、代码复制、标签分享和真实相关推荐。
- 首页：沿用同一视觉语言，显示品牌介绍、真实统计和最新文章，不保留旧版深色大封面。
- 搜索：保留 NexT 本地搜索能力，改为设计图中的白色搜索结果界面。

## 数据与交互

新增 Hexo 构建期生成器输出 `design-data.json`，包含公开文章的标题、链接、日期、分类、标签、摘要和封面。前端只用这份数据增强归档筛选、精选文章和相关推荐；加载失败时保留 Hexo 原生内容作为降级。移动导航、代码复制、链接分享和本地搜索均保留键盘可用状态。

## 验收

- `npm run clean && npm run build` 成功。
- 关于、分类、归档、文章、首页和搜索在 1440x960 与 390x844 下无横向溢出或内容遮挡。
- 分类筛选、移动菜单、搜索、代码复制和相关推荐链接可用。
- 仅提交源码和设计文档，不提交构建缓存 `db.json`。
