# 2022 年文章差异化扩写设计

## 目标

2022 年现有 9 篇文章已经形成“微服务认知、组件实践、基础设施、可观测性、年度总结”的时间线，但单篇只有约 946 至 1525 字，结构高度相似，缺少版本约束、完整配置、验证命令和故障场景。本次保留标题、发布日期、分类和线上 URL，重写正文，使这一组文章能够独立阅读，也能按时间顺序组成后端架构成长路线。

## 写作差异

| 文章 | 写作形式 | 目标篇幅 | 重点 |
| --- | --- | ---: | --- |
| 微服务架构初体验 | 架构决策记录 | 约 3000 字 | 拆分边界、数据归属、一致性和演进顺序 |
| Spring Cloud 学习笔记 | 分层学习地图 | 约 3500 字 | 组件职责、版本兼容和排查顺序 |
| Nacos、Gateway、OpenFeign 实操 | 端到端实验手册 | 约 4300 字 | 注册、路由、调用、超时和常见错误 |
| RabbitMQ 可靠性设计 | 故障链路复盘 | 约 4100 字 | 投递确认、持久化、幂等、重试和死信 |
| Redis 高可用架构 | 方案对比与演练记录 | 约 3400 字 | 主从、Sentinel、数据损失窗口和客户端恢复 |
| Docker 与 Compose 实践 | 可执行部署教程 | 约 3900 字 | 镜像、网络、健康检查、数据卷和日志 |
| ELK 日志平台搭建 | 平台建设笔记 | 约 3600 字 | 结构化日志、采集链路、映射和生命周期 |
| Prometheus 监控部署 | 指标与告警设计手册 | 约 4200 字 | RED 指标、PromQL、低基数标签和告警质量 |
| 从单体到微服务总结 | 年度复盘随笔 | 约 2800 字 | 收益、代价、适用边界和下一阶段方向 |

## 内容约束

- Java 示例默认兼容 JDK 8，不使用 Spring Boot 3 或 Java 17 专属能力。
- Spring Cloud 示例以 Spring Boot 2.x、Spring Cloud 2021.x 的思路为基准，并提示通过 BOM 核对 Spring Cloud Alibaba 兼容版本。
- 所有配置使用示例地址和示例密码，明确生产环境不能照搬。
- 高风险命令、强制故障转移、消息重投和数据清理必须说明前置条件。
- 每篇保留不同的节奏，不强制使用相同标题数量和总结模板。

## 验收

- 9 篇文章均能被 Hexo 正确解析，标题、日期和 URL 保持不变。
- 字数和代码块数量存在合理差异，不出现同模板机械复用。
- 搜索索引仍为 70 篇，2022 年归档仍为 9 篇。
- 桌面端与 390px 移动端无页面级横向溢出，长配置可在代码块内部滚动。
