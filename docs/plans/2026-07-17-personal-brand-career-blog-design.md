# 个人技术品牌与求职导向博客改造设计

## 目标

在保留现有浅色编辑型视觉的基础上，让访问者在首屏回答三个问题：作者擅长什么、有哪些可信内容、怎样进一步了解或联系。博客继续服务长期知识沉淀，同时具备面向招聘方、技术负责人和同行的快速浏览路径。

本次不虚构公司、职位、项目规模或业务成果。能力证明来自已有文章、可验证的技术方向和公开 GitHub 主页。

## 信息架构

顶部导航调整为：首页、专题、归档、分类、关于。

首页按以下顺序组织：

1. 技术定位：Java 后端、系统稳定性、AI 编程实践。
2. 职业入口：查看代表专题、了解作者与职业机会。
3. 三条能力路径：AI 编程、Java 工程、稳定性排障。
4. 精选文章：能够代表分析、交付和复盘能力的文章。
5. 最新文章：保留时间流，但将站点公告从主列表中移出。

专题页提供三条有顺序的阅读路径。每条路径显示目标、文章数量、预计阅读时间和文章序号；文章详情页显示所属专题及上一篇、下一篇。

分类页不直接把 23 个历史分类作为主要导航，而是聚合成七个职业能力方向：Java 与 Spring、数据库与中间件、架构与微服务、稳定性与运维、AI 与开发工具、工程质量与协作、随笔与成长。历史分类 URL 和文章 Front Matter 保持不变。

## 数据结构

新增 `source/_data/brand.yml`，维护以下内容：

- `profile`：品牌定位、起始年份和职业入口文案。
- `tracks`：七个能力方向及匹配规则。
- `series`：三条专题的文章标题和阅读顺序。
- `featured`：首页代表文章。

`scripts/design-data.js` 在构建时校验标题引用，并把解析后的专题、能力方向、精选文章和文章扩展字段写入 `design-data.json`。浏览器只消费结构化结果，不在页面中重复维护文章 URL。

文章可选 Front Matter：

```yaml
verified: 2026-07-17
environment:
  - JDK 8
  - Spring Boot 2.x
```

没有这些字段的历史文章继续正常渲染，不显示空状态。

## 页面功能

### 首页

- 用“Java 后端工程师”替代泛化的博客描述。
- 数据指标改为记录年限、文章数量和核心专题数量。
- 新增能力路径和精选文章，保持全宽分区，不堆叠装饰卡片。
- 《博客重新出发》作为轻量站点更新提示，不占据最新文章首位。

### 关于页

- 增加“我能解决的问题”“代表内容”“职业机会与技术交流”。
- 保留技术栈和成长经历，不添加没有证据的工作履历。
- GitHub、RSS 和归档继续作为主要外部入口。

### 文章页

- 桌面端显示右侧粘性目录，移动端显示可折叠目录。
- 显示校验日期和验证环境。
- 增加专题顺序导航和 GitHub 文章纠错入口。
- 保留阅读进度、代码复制、分享与相关推荐。

### 分享与封面

- 2024、2026 年首页近期文章补充统一封面。
- 文章 `cover` 使用 PNG，正文仍可使用可缩放 SVG。
- Twitter Card 调整为 `summary_large_image`，提高社交平台预览稳定性。

## 降级与错误处理

- `design-data.json` 加载失败时，保留 Hexo 原生首页、分类和归档。
- 专题配置引用不存在的文章时，构建输出明确警告，页面跳过该条目。
- 目录只在文章存在两个以上二级或三级标题时生成。
- Clipboard API 失败时不伪造成功反馈，纠错链接始终可以直接打开。
- 响应式布局在 1180px 以下隐藏桌面目录，在 700px 以下切换为单列。

## 验收标准

- Hexo 构建成功，文章总数保持 77，原文章 URL 不变化。
- 首页首屏明确显示 Java 后端、稳定性和 AI 编程定位。
- 专题页三条路径的文章顺序、数量和阅读时间正确。
- 分类页展示七个能力方向，同时保留历史分类入口。
- 2025 年七篇文章显示校验信息，Java 重构文章显示 JDK 8 环境。
- 桌面文章目录可定位标题，390px 移动端无页面级横向溢出。
- 首页近期文章封面无破图，Open Graph 使用 PNG，Twitter Card 为大图模式。
- `db.json` 既有改动不进入提交。
