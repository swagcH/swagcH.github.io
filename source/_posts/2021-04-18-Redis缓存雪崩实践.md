# 背景

缓存雪崩通常不是单个 key 的问题，而是一批 key 在同一时间失效。


# 问题


```bash

```

# 分析

```text
风险点：
1. 大量 key 使用同一过期时间
2. 热点数据没有预热
3. Redis 故障时没有降级策略
4. 后端 DB 无保护
```

# 解决方案

```java
int baseSeconds = 30 * 60;
int randomSeconds = ThreadLocalRandom.current().nextInt(0, 10 * 60);
redisTemplate.opsForValue().set(key, value, baseSeconds + randomSeconds, TimeUnit.SECONDS);
```

```text
处理：过期时间随机化、热点预热、限流降级、多级缓存
```

# 总结

```text
复盘要点：
1. 先保留现场，再尝试恢复
2. 先确认影响范围，再判断根因
3. 日志、监控、配置、代码需要串起来看
4. 修复动作必须可验证
5. 故障结束后补充检查项和自动化规则
```
