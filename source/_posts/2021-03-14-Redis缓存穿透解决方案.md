# 背景

缓存穿透的典型特征是缓存未命中后大量请求直接打到数据库。

# 问题

```text
Redis miss rate: 78%
DB QPS: 2400 -> 9600
hot key pattern: product:not-exist:*
```

```bash
redis-cli --bigkeys
redis-cli monitor | grep product
```

# 分析

```java
Product product = redis.get(key);
if (product == null) {
    product = productMapper.selectById(id);
    if (product != null) {
        redis.set(key, product, 30, TimeUnit.MINUTES);
    }
}
```

# 解决方案

```java
String key = "product:" + id;
Product cached = redis.get(key);
if (cached != null) {
    return cached == EMPTY_PRODUCT ? null : cached;
}

Product db = productMapper.selectById(id);
redis.set(key, db == null ? EMPTY_PRODUCT : db, db == null ? 60 : 1800, TimeUnit.SECONDS);
return db;
```

```text
方案：缓存空值 + 参数校验 + 布隆过滤器
```
