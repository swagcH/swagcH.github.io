# 背景

消息丢失要按生产、交换机、队列、消费确认四段链路排查。

# 问题

```text
订单已支付，但积分未到账
producer log: message sent
consumer log: no message received
queue ready=0 unacked=0
```

```bash
rabbitmqctl list_queues name durable messages_ready messages_unacknowledged
rabbitmqctl list_exchanges name type durable
```

# 分析

```text
排查链路：
producer confirm -> exchange durable -> queue durable -> binding key -> consumer ack -> retry/dlx
```

```java
rabbitTemplate.convertAndSend("point.exchange", "point.add", message);
```

# 解决方案

```java
rabbitTemplate.setConfirmCallback((correlationData, ack, cause) -> {
    if (!ack) {
        log.error("message publish failed, id={}, cause={}", correlationData.getId(), cause);
    }
});
```

```yaml
spring:
  rabbitmq:
    publisher-confirm-type: correlated
    publisher-returns: true
    listener:
      simple:
        acknowledge-mode: manual
```

# 总结

```text
复盘要点：

4. 修复动作必须可验证
5. 故障结束后补充检查项和自动化规则
```
