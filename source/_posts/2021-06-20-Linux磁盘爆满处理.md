# 背景

磁盘爆满处理要先恢复服务写入能力，再定位增长来源。

```text

```

# 问题

```bash
df -h
Filesystem      Size  Used Avail Use% Mounted on
/dev/vda1        40G   40G     0 100% /
```

```text
应用报错：No space left on device
MySQL 写入失败
日志无法继续滚动
```

# 分析

```bash
du -h --max-depth=1 / | sort -hr | head
du -h --max-depth=1 /var/log | sort -hr | head
lsof | grep deleted | head
```

# 解决方案

```bash
find /var/log -name "*.log" -mtime +7 -type f -delete
journalctl --vacuum-time=7d

# 处理已删除但仍被进程占用的文件
lsof | grep deleted
systemctl restart app
```

# 总结

```text
复盘要点：
1. 先保留现场，再尝试恢复
2. 先确认影响范围，再判断根因
3. 日志、监控、配置、代码需要串起来看
4. 修复动作必须可验证
5. 故障结束后补充检查项和自动化规则
```
