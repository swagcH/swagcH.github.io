# 背景

2018 年春节回来，我下定决心从 C 语言转向 Java 后端开发。上学时学过一点 C 语言，顶多写过一些控制台排序算法，对"企业级开发"完全没概念。周围同学有搞 PHP 的，有搞 Python 的，选 Java 主要是看中了它的就业面广、生态成熟。

当时手头参考资料主要是两样：**廖雪峰的 Java 教程**（在线版）和 **《Head First Java》** 这本经典入门书。廖雪峰的教程偏实战，直接讲 Eclipse 怎么配、Maven 怎么用，而 Head First 用大量插图讲面向对象思想，两本搭配着看效果不错。

因为之前只用过 Code::Blocks 写 C 语言，对 JDK、JRE、IDE 这些概念完全分不清，所以第一步搭建环境就折腾了好几天。

# 问题

### 1. JDK 版本选择困难

当时 Oracle 在 2017 年 9 月刚发布了 JDK 9，官网上最显眼的位置就是 JDK 9 的下载链接。JDK 8 要往下翻半天才能找到。作为新手真的纠结了很久——装新不装旧？但是网上搜了一圈，几乎所有教程都在说 JDK 8 是 LTS（长期支持版本），更稳定，企业里用的最多。廖雪峰的教程里也明确写了建议用 JDK 8。最后还是选了 JDK 8u161。

### 2. 环境变量配置后还是找不到 java 命令

这是我踩的第一个坑。按照教程配置了 `JAVA_HOME`、`Path`、`CLASSPATH`，打开新命令行窗口输入 `java -version`，结果报：

```
'java' 不是内部或外部命令，也不是可运行的程序或批处理文件。
```

当时心态有点崩，明明按照步骤一步一步来的啊。来来回回检查了好几遍才发现问题。

### 3. Eclipse 启动报错

装好 JDK 后下载了 Eclipse Oxygen（当时的最新版），结果双击启动图标直接弹出一个错误对话框：

```
Failed to create the Java Virtual Machine
```

一脸懵，刚装好的环境怎么就起不来？

*Eclipse 启动时提示 JVM 创建失败*

# 分析

回过头来分析这几个问题，其实都不复杂，但对新手来说每个都是拦路虎。

### JDK 版本

JDK 9 引入了模块化系统（Jigsaw），算是一次比较大的架构变动。虽然新特性很吸引人，但 LTS 版本更稳妥这个道理现在懂了。JDK 8 一直到 2018 年初都还是绝对的主流，公司项目基本都在用，遇到问题网上也更容易找到解决方案。

### 环境变量问题

仔细排查后发现是犯了两个低级错误：

1. **路径多了尾部斜杠**：配置 `JAVA_HOME` 时写成了 `C:\Program Files\Java\jdk1.8.0_161\`（多了反斜杠），导致 `%JAVA_HOME%\bin` 解析出来变成了 `C:\Program Files\Java\jdk1.8.0_161\\bin`，双斜杠导致路径无效。

2. **配置后没重新打开命令行**：环境变量改了之后，已经打开的命令行窗口不会自动刷新，需要关掉重新打开。

### Eclipse JVM 参数

打开 Eclipse 安装目录下的 `eclipse.ini` 看了下，默认配置是这样的：

```
-Xms256m
-Xmx1024m
```

我的笔记本当时只有 4GB 内存，系统和其他软件占掉一大半，Eclipse 默认的 `-Xmx1024m`（最大堆内存 1024MB）对这台机器来说太大了，JVM 启动时分配不到足够的连续内存空间，所以直接崩了。

# 解决方案

### 第一步：安装 JDK 8u161

从 Oracle 官网下载了 `jdk-8u161-windows-x64.exe`，双击安装，安装路径选择默认的 `C:\Program Files\Java\jdk1.8.0_161`。安装过程中会同时安装 JRE，一路下一步就好。

### 第二步：配置环境变量

在 Windows 10 中按 `Win + R` 输入 `sysdm.cpl`，在"高级"选项卡里点击"环境变量"，分别配置以下三个变量：

#### 新建系统变量：JAVA_HOME

```
变量名：JAVA_HOME
变量值：C:\Program Files\Java\jdk1.8.0_161
```

#### 编辑系统变量：Path

在 Path 变量的值末尾追加（注意分号分隔）：

```
%JAVA_HOME%\bin
```

#### 新建系统变量：CLASSPATH（可选）

```
变量名：CLASSPATH
变量值：.;%JAVA_HOME%\lib\dt.jar;%JAVA_HOME%\lib\tools.jar
```

> 注意前面那个点号 `.` 代表当前目录，必须要加。

*Windows 10 环境变量配置窗口*

### 第三步：验证安装

配置完成后，重新打开一个命令行窗口，依次输入以下命令验证：

```bash
C:\Users\chenzixin> java -version
java version "1.8.0_161"
Java(TM) SE Runtime Environment (build 1.8.0_161-b12)
Java HotSpot(TM) 64-Bit Server VM (build 25.161-b12, mixed mode)

C:\Users\chenzixin> javac -version
javac 1.8.0_161
```

看到这个输出时心里踏实了不少，说明 JDK 安装和环境变量都生效了。

### 第四步：编写第一个 Java 程序

在 `D:\JavaWorkspace` 目录下新建 `Test.java`：

```java
public class Test {
    public static void main(String[] args) {
        System.out.println("Hello Java! 环境搭建成功！");
        System.out.println("JDK 版本: " + System.getProperty("java.version"));
    }
}
```

在命令行中编译和运行：

```bash
D:\JavaWorkspace> javac Test.java

D:\JavaWorkspace> java Test
Hello Java! 环境搭建成功！
JDK 版本: 1.8.0_161
```

第一个 Java 程序跑起来的那一刻，感觉之前折腾的这几天的辛苦都值了。

### 第五步：安装 Eclipse 并调整 JVM 参数

下载 Eclipse IDE for Java Developers（Oxygen 版本），解压到 `D:\eclipse`。

打开 `D:\eclipse\eclipse.ini`，找到 JVM 参数相关配置，修改前：

```
-Xms256m
-Xmx1024m
```

修改后：

```
-Xms256m
-Xmx512m
```

只改了一处——把 `-Xmx` 从 `1024m` 降到了 `512m`。改完后重启 Eclipse，顺利启动成功。

*Eclipse Oxygen 启动后的欢迎界面*

### 第六步：配置 Eclipse 的 Workspace

我选择了 `D:\JavaWorkspace` 作为工作空间目录，然后在 Eclipse 中配置已安装的 JDK：

1. 点击菜单 `Window` -> `Preferences`
2. 展开 `Java` -> `Installed JREs`
3. 确保指向的是 `C:\Program Files\Java\jdk1.8.0_161`

这样配置后，Eclipse 就自动识别了 JDK 的类库和编译选项，可以在 IDE 里直接创建和运行 Java 项目了。

# 总结

这次搭建环境的经历让我这个 Java 新手学到了不少东西：

1. **JDK 选择 LTS 版本最稳妥**。JDK 9 虽然新，但 JDK 8 作为 LTS 版本在企业中广泛使用，遇到问题更容易找到解决方案。对于初学者来说，稳定压倒一切。

2. **环境变量配置要仔细检查路径**。多一个斜杠、少一个分号都可能导致配置不生效。配置完一定要重新打开命令行窗口再测试，这个坑后来再也没踩过。

3. **IDE 的 JVM 参数要根据机器配置调整**。Eclipse 默认的 JVM 参数是为配置较高的机器准备的，2018 年主流笔记本还是 4GB~8GB 内存，默认的 1024m 对低配机器来说偏大。`eclipse.ini` 里的 `-Xmx` 参数控制最大堆内存，根据自己电脑的内存大小酌情调整就好。后来的 IntelliJ IDEA 也有类似问题，`idea64.exe.vmoptions` 里面的参数同样需要根据机器配置手动调整。

4. **建议新手先熟悉命令行编译运行再依赖 IDE**。虽然 Eclipse 很方便，但用命令行编译运行能让人更好理解 Java 的编译原理——Java 源代码通过 `javac` 编译成字节码（`.class` 文件），再由 JVM 解释执行。理解了这套流程，后面学 Maven、Gradle 这些构建工具也会轻松很多。

最后的最后，记录一下当时的主要软件版本，方便以后回顾：

| 软件 | 版本 |
|------|------|
| JDK | 1.8.0_161 (build 1.8.0_161-b12) |
| Eclipse | Oxygen (4.7) |
| 操作系统 | Windows 10 专业版 64位 |
| 笔记本内存 | 4GB |

到现在我写这篇博客时，已经能用 Java 写一些简单的 Web 应用了。回头看看搭建环境这件事，其实没那么难，只是对一个新领域的未知让人感到畏惧而已。动手去做，遇到问题就查、就问、就试，总能解决。
