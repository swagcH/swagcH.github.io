# 在服务器上装 Hermes：从零到能跟它聊天，我踩了哪些坑

说真的，AI Agent 这东西装在本地电脑上其实挺尴尬的——你总不能把笔记本一直开着，让它 24 小时待命吧。

所以我就想：能不能把它装到我的云服务器上？让它一直跑着，微信/飞书/邮件随时能叫起来干活。

折腾了一晚上，还真搞定了。这篇文章就把我做的每一步都写下来，包括中间踩的坑，给也想这么干的人一个参考。

<!-- more -->

## 先说我要达成什么

我想要的是这样：

- Hermes 跑在云服务器后台，关掉 SSH 它也照常工作
- 在飞书里发消息能直接调它（不是网页版那种）
- 服务器重启了不用我手动起来

听起来简单对吧。实际上每一步都有坑。

### 🟢 第一个选择：装哪里

<div style="margin:12px 0;padding:14px 18px;border-radius:8px;background:#f6f8fa;border-left:4px solid #2da44e;font-family:'SF Mono',Monaco,monospace;font-size:13.5px;line-height:1.7;">
<span style="color:#57606a;">Install directory</span> [<span style="color:#1f2328;">/usr/local/lib/hermes-agent</span>]:
</div>

直接回车用默认 `/usr/local/lib/hermes-agent` 就行。改路径后面配 systemd 会麻烦。

### 🟡 第二个选择：要不要启 gateway

<div style="margin:12px 0;padding:14px 18px;border-radius:8px;background:#fff8c5;border-left:4px solid #d4a72c;font-family:'SF Mono',Monaco,monospace;font-size:13.5px;line-height:1.7;">
<span style="color:#57606a;">Start the gateway now?</span> [<span style="color:#1f2328;font-weight:600;">Y</span>/n]:
</div>

**选 Y**。gateway 就是 Hermes 跟外部世界（飞书、微信）通信的桥梁。不启它就是个命令行工具，不能在飞书里调它。

### 🔴 第三个选择：要不要开机自启

<div style="margin:12px 0;padding:14px 18px;border-radius:8px;background:#ffebe9;border-left:4px solid #cf222e;font-family:'SF Mono',Monaco,monospace;font-size:13.5px;line-height:1.7;">
<span style="color:#57606a;">Enable systemd service?</span> [<span style="color:#1f2328;font-weight:600;">Y</span>/n]:
</div>

**选 Y**。你不会想每次重启服务器都手动 `hermes gateway start` 吧。

## 第四步：配飞书（或者你用的 IM）

这一步是**真正能聊天**的环节。Hermes 支持飞书、Slack、WhatsApp、邮件……我自己用飞书，所以只讲飞书。

### 4.1 先在飞书开放平台建个应用

打开 [飞书开放平台](https://open.feishu.cn/app)，登录后：

1. 点「创建企业自建应用」
2. 名字随便起，比如「我的 Hermes 助手」
3. 头像、描述随便填
4. 进应用详情页，记下 **App ID** 和 **App Secret**（后面要用）

### 4.2 配权限

在应用的「权限管理」里，至少要勾这几个：

<div style="margin:12px 0;border-radius:8px;background:#f6f8fa;border:1px solid #d0d7de;overflow:hidden;">
<div style="background:#eaeef2;padding:8px 14px;border-bottom:1px solid #d0d7de;font-size:12px;color:#57606a;font-weight:600;">📋 飞书权限清单</div>
<div style="padding:12px 16px;font-family:'SF Mono',Monaco,monospace;font-size:13px;line-height:1.9;">
<div><span style="color:#cf222e;">●</span> <span style="color:#8250df;">im:message</span> <span style="color:#8b949e;">— 收发消息</span></div>
<div><span style="color:#cf222e;">●</span> <span style="color:#8250df;">im:message:send_as_bot</span> <span style="color:#8b949e;">— 以机器人身份发消息</span></div>
<div><span style="color:#cf222e;">●</span> <span style="color:#8250df;">im:message.p2p_msg</span> <span style="color:#8b949e;">— 私聊（1v1 跟它聊）</span></div>
<div><span style="color:#cf222e;">●</span> <span style="color:#8250df;">im:message.group_at_msg</span> <span style="color:#8b949e;">— 群聊 @ 机器人</span></div>

申请完要点「发布版本」才生效。

### 4.3 配事件订阅

在「事件订阅」里：

- 请求网址 URL：填 `https://你的服务器公网IP:端口/hermes/feishu/webhook`
  - 注意要先用 nginx 或别的反代把 HTTPS 配上，**飞书只接受 HTTPS**
  - 或者用 [ngrok](https://ngrok.com) 这种内网穿透

> 💡 **小贴士**：加密策略选「加密」或「明文」都行，新手选明文调试更简单。

## 第五步：跑个真任务试试

## 我踩的坑（建议你提前避）

### 坑 1：systemd 用错了 user 还是 system

Hermes 装的是 `~/.config/systemd/user/hermes-gateway.service`，是**用户级**的。

所以**所有命令都要加 `--user`**：

<div style="display:grid;grid-template-columns:1fr 1fr;gap:12px;margin:12px 0;">
<div style="border-radius:8px;overflow:hidden;border:1px solid #6ee7b7;">
<div style="background:#d1fae5;padding:6px 12px;font-size:11px;font-weight:600;color:#065f46;">✅ 正确</div>
<div style="padding:10px 12px;background:#f0fdf4;font-family:'SF Mono',Monaco,monospace;font-size:12px;color:#1f2328;">systemctl <span style="color:#cf222e;">--user</span> status hermes-gateway</div>
</div>
<div style="border-radius:8px;overflow:hidden;border:1px solid #fca5a5;">
<div style="background:#fee2e2;padding:6px 12px;font-size:11px;font-weight:600;color:#991b1b;">❌ 错误</div>
<div style="padding:10px 12px;background:#fef2f2;font-family:'SF Mono',Monaco,monospace;font-size:12px;color:#1f2328;">systemctl status hermes-gateway</div>
<div style="background:#fee2e2;padding:6px 12px;font-size:11px;color:#991b1b;">→ 找不到服务</div>
</div>
</div>

> 💡 如果你服务器开了多用户，gateway 跟用户绑定。用户退了 gateway 也停。要全局用就改成 system 级，但官方不推荐。

### 坑 2：Node 版本 < 20 装不上

<div style="margin:12px 0;padding:12px 16px;border-radius:8px;background:#fff8c5;border-left:4px solid #d4a72c;font-family:'SF Mono',Monaco,monospace;font-size:13px;color:#1f2328;">
⚠ ERROR: Hermes Agent requires Node.js 20+ (found 18.17.0)
</div>

老老实实装新版。

### 坑 3：飞书事件订阅 URL 必须 HTTPS

这个上面提了。如果你懒得搞反代，用 `ngrok` 一行命令解决：

<div style="background:linear-gradient(90deg,#7c3aed 0%,#4c1d95 100%);padding:8px 14px;display:flex;align-items:center;gap:8px;border-bottom:1px solid #30363d;">
<span style="color:#a78bfa;">●</span>
<span style="color:#a78bfa;">●</span>
<span style="color:#a78bfa;">●</span>
<span style="color:#c4b5fd;font-size:12px;margin-left:8px;font-family:'SF Mono',Monaco,monospace;">~ ngrok</span>
</div>
<div style="padding:14px 16px;font-family:'SF Mono','JetBrains Mono',Monaco,Consolas,monospace;font-size:13.5px;line-height:1.7;">
<span style="color:#7ee787;">$</span> <span style="color:#d2a8ff;">ngrok</span> <span style="color:#79c0ff;">http</span> <span style="color:#79c0ff;">8765</span>

把 ngrok 给你的 https 地址填进飞书就行。**仅限测试用**，生产环境别这么干。

### 坑 4：防火墙没开

<div style="margin:12px 0;border-radius:8px;background:#f6f8fa;border:1px solid #d0d7de;overflow:hidden;">
<div style="background:#eaeef2;padding:8px 14px;border-bottom:1px solid #d0d7de;font-size:12px;color:#57606a;font-weight:600;">📋 排查步骤</div>
<div style="padding:12px 16px;font-family:'SF Mono',Monaco,monospace;font-size:13px;line-height:1.9;">
<div><span style="color:#1f2328;font-weight:600;">①</span> 看端口监听</div>
<div style="margin-left:20px;color:#57606a;">ss -tlnp | grep -E '8765|hermes'</div>
<div style="margin-top:4px;color:#1f2328;">没监听 = gateway 没起来</div>
<div style="margin-top:8px;"><span style="color:#1f2328;font-weight:600;">②</span> 起了但外面连不上 = 防火墙</div>
<div style="margin-left:20px;color:#57606a;">firewall-cmd --add-port=8765/tcp --permanent</div>
<div style="margin-left:20px;color:#57606a;">firewall-cmd --reload</div>
</div>
</div>

> ⚠️ **云服务器（阿里云/腾讯云）还要去控制台的安全组里开端口**，不然白搭。

### 坑 5：内存不够被 OOM kill

Hermes gateway 启动后内存大概 400-600MB。如果你的服务器只有 1GB 内存，跑它一个就吃满了，再加别的服务就被 OOM。

> 💡 **建议**：至少 2GB 内存起步。

## 最后说两句

装完 Hermes 在服务器上跑了快两周了，最大的感受是：**这玩意真的能当个私人助手用**。

不是那种"打开网页问一句、答完就走"的玩具，而是真的在你服务器上待命、知道你的环境、能直接动你文件的助手。

比如我最近写代码遇到一个 Node 的报错，直接在飞书里描述给它，它让我贴 log、让我跑几条命令诊断，最后定位到是某个 npm 包的版本冲突——整个过程我手都没离开手机。

当然它不是万能的。复杂决策、需要物理操作的事它干不了。**但作为一个 7x24 待命的程序，它比大部分同类都靠谱**。

如果你们也想装，按我上面写的顺序走一遍，应该 1-2 小时搞定。中间卡住了欢迎来问我——别一个人闷头搞，那是最慢的方式。
