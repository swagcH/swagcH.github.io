# 背景

慢查询不能只看 SQL 文本，需要结合执行计划、索引、扫描行数和返回字段。

```text
记录类型：故障排查
记录年份：2021
记录方式：现象、命令、日志、代码、配置、结论
```

# 问题

```sql
set global slow_query_log = 'ON';
set global long_query_time = 1;
```

```text
# Time: 2021-02-21T14:22:19
# Query_time: 6.834 Lock_time: 0.001 Rows_sent: 20 Rows_examined: 581239
select * from order_info where user_id = 1001 order by created_at desc limit 20;
```

# 分析

```sql
explain select *
from order_info
where user_id = 1001
order by created_at desc
limit 20;
```

```text
type: ALL
possible_keys: idx_user_id
key: NULL
rows: 581239
Extra: Using where; Using filesort
```

# 解决方案

```sql
alter table order_info
add index idx_user_created(user_id, created_at);

explain select id, order_no, order_status, created_at
from order_info
where user_id = 1001
order by created_at desc
limit 20;
```
