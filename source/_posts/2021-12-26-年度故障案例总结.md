# 背景

年度故障总结的重点不是罗列事故，而是把重复问题转成规范和工具。

```text
记录类型：故障排查
记录年份：2021
记录方式：现象、命令、日志、代码、配置、结论
```

# 问题

```text
2021 故障分类：
- 慢 SQL：3 起
- 缓存问题：2 起
- 部署配置：2 起
- 并发问题：2 起
- 消息可靠性：1 起
```

# 分析

```text
复盘模板：
1. 故障时间线
2. 影响范围
3. 直接原因
4. 根本原因
5. 恢复动作
6. 后续改进
7. 责任人和截止时间
```

# 解决方案

```text
沉淀项：
- 慢查询巡检脚本
- Redis key 过期时间规范
- 线程池监控指标
- 发布前配置检查清单
- MQ 可靠投递模板
```

# 总结

```text
复盘要点：
1. 先保留现场，再尝试恢复
2. 先确认影响范围，再判断根因
3. 日志、监控、配置、代码需要串起来看
4. 修复动作必须可验证
5. 故障结束后补充检查项和自动化规则
```
